사각형의 4개의 점이 존재한다.
그곳 중앙에 점 한개를 찍어 4방향에 점을 찍는다.
즉 0 : 4개, 1 : 9개, 2 : 25개의 점이 찍히게 된다.
사각형의 개수를 알아내고 그곳에 4개의 점을 찍으면 된다.
하지만 여기서 문제가 발생한다. 바로 중복 처리이다.
바로 옆으로 붙어있을 경우 점은 1개로 측정이 되어야된다.
즉 4각형의 개수가 1개 이상일경우, 다른 로직을 세워야된다.
이걸 수학 공식으로 풀고 싶은데 아무리 생각해도 그리드 알고리즘밖에 안 떠오른다.

자 힌트를 얻어서 변의 개수가 늘어간다는 소식을 들었다!
초기 상태의 변의 점은 2개
.-.이다.
점 + (점 -1)
1 : 2 + (2 -1) = 3 : .-.-.
2 : 3 + (3 -1) = 5: .-.-.-.-.
총 변의 제곱을 통해 구하면 다음 공식이 나온다.

N : 점의 개수

N + N -1 이 된다.
그런데 해당 사항엔 반복적으로 1개씩 증가할 수 밖에 없다는 불편한 진실이 자리 앉아있다.
여기서 중요한 규칙을 발견했다.
1 : 2 + 2 -1 : 3
2 : 3 + 3 -1 : 5
3 : 4 + 4 -1 : 7
4 : 5 + 5 -1 : 9
5 : 6 + 6 -1 : 11
자 여기서 1개씩 빼면 2, 4, 6, 8, 10 으로 2의 제곱이 된다.
그래서 2N -1 수식을 2^N +1 수식을 통해 반복이 아닌 제곱으로 진행하면 O(1)로 문제를 해결할 수 있다!
최종 수식은 (2^N + 1)^2 가 된다.
