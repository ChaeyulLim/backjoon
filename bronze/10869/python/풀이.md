기존의 2개의 정수 값을 입력 받기 위해
input().split() 으로 입력받은 2개의 문자를 공백을 기준으로 나눴다.
하지만 다시 한번 int 형으로 형 변환을 각자 해줘야되는 번거로움이 있었다.
그를 개선할 매소드인 map() 이 존재한다.
사용은 map(function, data) 로 이루어져 있고
뒤의 data 에 맞춰 각각 function을 진행한다는 뜻이다.
즉 map(int, input().split())을 하게 될 경우
input().split() 메소드를 통해 나온 데이터들을 int function 으로 변환되어 전부 int 형으로 재 저장된다는 뜻이다.
이렇게 2개의 int형태를 기준으로 +, -, *, //, % 까지 계산해 출력하였다.
