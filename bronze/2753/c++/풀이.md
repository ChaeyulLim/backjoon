윤년의 조건이 잘 나와있다.
윤년이란 4의 배수이면서 100의 배수가 아닐때 또는 400의 배수일 때이다.
수식은 다음과 같다
year % 4 == 0 : 4의 배수
year % 100 != 0 : 100의 배수가 아닐때
year % 400 == 0 : 400의 배수일 때

배수는 특정 값을 곱한 값이다.
2의 배수는 2를 꾸준히 곱한 값이며, 이를 2로 나눈 값의 나머지는 0이여야된다.
즉 year % 2 == 0 은 year은 2의 배수가 된다.

year % 4 == 0 && year % 100 != 0 || year % 400
의 수식이 된다.

하지만 문제를 잘 읽어보면 뭔가 착오가 있었던 것 같다.
내가 해석한 윤년의 정의는
4의 배수 and (100의 배수가 아닌 or 400의 배수 일때) 로 해석했지만
예제를 보면
(4의 배수 and 100의 배수가 아닌) or 400의 배수 일때 로 해석되었다.
즉 수식은 
(year % 4 == 0 && year % 100 != 0) || year % 400
로 볼 수 있다.
