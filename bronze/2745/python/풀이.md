진법 변환인데 수학적인 공식이 많이 나와 이번 챕터는 어려울 것 같다.
모든 공식인 사칙 연산을 여러번 하면 안되는 문제는 없다. 하지만 그러면 효율이 안나오니까..
우선 진번 변환하는데 horner 수학 공식이 가장 효율적인 것 같다.
이 방식은 인수분해를 해 가면서 곱셈을 최소화 하는 방식인 듯 하다.

ABCD 라는 36 진법을 기준으로 수식을 펼치면 다음과 같다.

AX36^4 +BX36^3 +CX36^2 +DX36 + E

36(A*36^3 + B*36^2 + C*36 + D) + E
36(36(A*36^2 + B*36 + C) + D) + E
36(36(36(A*36 + B) + C) + D) + E


최종적으로 다음 1줄을 계산하면 된다.


지금 해당 코드에선 인수분해를 가상으로 진행한 상태로 진행해야될 듯 하다
단순하니까 가능 한 것 같다.
f1 = A * 36 + B
f2 = f1 * 36 + B
f3 = f2 * 36 + C
f4 = f3 * 36 + D
f5 = f4 * 36 + E
로 변환이 가능할 듯 싶다.
