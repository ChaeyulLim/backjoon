해싱을 사용하는데 그의 수식이 수학적으로 뭐 하는 수식인 것 같다.
해당 수식을 풀어보면 다음 수식이 나온다.
H = c₀×31⁰ + c₁×31¹ + c₂×31² + ... + c_{L-1}×31^{L-1}

간단하게 풀어 문자열이 존재하는데 a = 1, b = 2, c = 3, d = 4 ... 로 숫자로 변환한다.
그리고 입력의 문자들의 X 31^N을 추가 연산한다.

예들들면
abdc : 1, 2, 4, 3
(1*31^0 % m) + (2*31^1) % m + (4*31^2) % m + (3*31^3) % m = Result 가 된다.
