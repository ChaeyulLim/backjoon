이상한 곱셈은 A * B 로 행렬곱에 가깝다.
A와 B의 각 자릿수를 분리하고
A를 기준으로 B 각 자리수를 곱해서 출력하는 문제이다.
123 * 45 를 예로 들면
1*4 + 2*4 + 3*4 + 1*5 + 2*5 + 3*5 = 54 가 된다. 이를 출력하라.


이것도 int 로도 충분할줄 알았는데 범위가 10,000 단위인줄 알았지만 자리 수가 1만자리수까지 존재한다는 뜻이었네..
그래서 이는 ai의 힘을 빌려 작성했다.
바로 collections 의 Counter 로 문자열이 몇개 있는지 확인해주는 매소드를 사용했다.
이를 통해 i*ac[i]로 각 자리수의 값이 몇개가 있는지 확인해주는 값이다.
0 자리수의 몇개가 있는가 = ac[i]개 있다 로 수식이 된다.
이는 브루트포스 알고리즘으로 모든 값을 효율적으로 반복을 최소화로 돌며 모든 값을 확인하는 수식이다.
이 문제 생각보다 어려웠다.
