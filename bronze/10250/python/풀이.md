H * W의 호텔이 존재한다.
여기서 오는 N번째 손님은 비어있는 칸들 중 가장 적게 걷는 칸을 선호한다고 한다.
가장 작은 W인데 그 중에 H가 작은 순으로 배정받고 싶은 것이다.

간단하게 생각해서
H / N을 하게 되면 W를 알 수 있다.
또한 H % N을 하게 되면 H도 알 수 있을 것이다.
테스트 해보자.

처음엔 수식이
height = n % h
width = n / h +1
였다. 하지만 테스트 케이스에서 만약 h : 6, n : 6일 경우 6층의 1이 아닌 0의 2층으로 출력된다. 이는 둘이 같을 때 0으로 나오는 예외처리를 하지 않았기 때문이다.
그래서 조건에 n % h == 0 일 경우 h그대로, (n / h)로 출력하고
그게 아니라면 정상적으로 n % h, n / h +1 을 진행하면 된다.
