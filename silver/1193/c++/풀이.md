우선 지그제그로 이동하면서 증가한는데 이는 중요하게 핵심을 찾아야된다.
우선 N이 몇 번째의 행렬에 존재하는지와 정확한 좌표는 몇인지가 제일 중요하다.
우선 N이 몇번째에 존재하는지를 알기 위해 k +1 == 분모+분자 의 공식이 존재한다.

자 이제 k는 +1씩 하면 총 개수가 나오는데 이때 루프 대신
등차수열 합이라는 공식을 사용한다. 이는 간단하게 +1씩 존재하는 모든 경우를 더한다라는 뜻이다. k(5) = (1 + 2 + 3 + 4 + 5), k(5) = k(k +1) /2 와 같다고 보면 된다.
이제 k의 번지수 를 n 과 비교했을 때 n이 더 클 경우 k는 n의 번지수가 된다.
이제 번지수를 찾았으니 정확한 좌표를 찾아야된다.

정확한 좌표는 n - k의 시작점 이 되어야된다.
이전에 등차수열을 통해 n이 몇 번째에 있는지 확인했다.
같은 공식을 사용하는데 이번엔 k-1을 해준다. 이는 (k+1)은 마지막 번호이고
(k-1)은 첫번째 번호를 뜻하기 때문이다.

자 이제 좌표는 정해 졌다. 이제 시작점을 찾아야되는데 여기서
결정적인 규칙이 존재한다.
시작점의 홀수는 n/1, 짝수는 1/n 으로 시작한다.

짝수일 경우 pos/k-pos +1 이 된다.
