내가 문제를 자 못 읽었다.
무슨 값이나오든 간에 my, mx 는 8 이상의 숫자들로 입력된다.
이건 단순히 체스 판을 칠하는게 아니라 8*8로 잘라야된다.
즉 모든 경우의 수를 재면서 해야된다는 것이다.

이런 젠장 그래도 메인 로직은 살릴 수 있을 것 같다 수정로직은 총 4중 for 이 될 것 같다. 만약 2개의 수치가 겹첬다면 3중으로 끝났을 것 같긴한데
그게 아니라 모든 수를 전부 살펴 봐야되니까 뭐

for y <= my - 8
    for x <= mx - 8
        for y+1
            for x+1
