우리 포켓몬 마스터 이다솜 씨를 위해 도감을 출력하는 프로그램을 작성한다.
n개의 포켓몬 이름과 m개의 도감 번호 OR 포켓몬 이름 이 입력되는데
위의 n개의 포켓몬 들의 이름 OR 도감 번호를 출력한다.
name -> number
number -> name 으로 출력한다.

일단 입력과 출력은 최소화 하기 위해 
std::ios::sync_with_stdio(false);
std::cin.tie(nullptr);
를 통해 c언어와의 연결을 끊어낸다.

찾아내는 건 배열을 hash map 을 통해 key : value 로 진행한다.
unordered_map 를 사용한다.
