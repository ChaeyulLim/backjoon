n개의 출입 로고가 존재한다.
enter : 출근, leave : 퇴근 처리를 한다.
이는 unordered_set 알고리즘으로 관리한다.
그 후 sort 로 정렬해 출력하면 될 것 같다.



지금 set 과 unordered_set 의 차이에 대해 알아보았다.
set 은 자동 정렬이 되는 반면에 unordered_set 은 자동정렬이 안된다.
효율로 따졌을 땐 unordered_set 이 시간 복잡도에선 우위를 격는다.
하지만 해시 충돌로 인해 최악을 격었을 땐 O(N)이 된다고 한다.
반면에 set 은 동일하게 O(log n)이다. 따라서 정말 최적화가 필요하다, 해시 충돌도 안날 자신 있고, 정렬도 필요 없다 할 땐 unordered_set 이 적합 한 것 같다.

2가지 버전을 작성했는데 둘다 통과가 된 것 같다. 하지만 별도의 정렬을 해줘야되므로 set 이 더 적합한 것 같다. 그러므로 set 으로 작성한걸 기록한다.
